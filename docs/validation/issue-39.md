# 이슈 #39 구현 검증

2026-09-10, Windows PowerShell, Python 3.12.10.
범위: [네이버 후보 조회와 안전한 재사용 #39](https://github.com/snowjaewon/OfficialDeliciousMap/issues/39).
사용법과 직렬화 계약은 [지오코딩](../geocoding.md)에 있다.

## 구현과 TDD

부모 #36에서 사용자가 확정한 공개 CLI 경계를 그대로 쓴다. 새 테스트는 실제 네이버 어댑터의
요청 구성·응답 해석·오류 변환과 실제 업소 판정·저장·마커 연결을 실행하고, HTTP 경계에만
합성 응답을 주입한다(`cli.main(argv, transport=...)`). 네트워크 차단·임시 디렉터리·합성
선행 산출물을 사용하며 실제 키·유료 호출은 없다. 조회 자체를 항상 성공하는 가짜로 바꾸지 않았다.

실패→최소 구현→통과를 확인한 동작:

- 근거가 가리키는 후보만 채택하고 검색 순위 첫 후보는 건너뛰는 조회: 최초 `transport` 인자 부재로 실패.
- 로컬 후보와 네이버 응답이 같은 사실을 줄 때 같은 업소·마커: 최초 조회 경로 부재로 실패.
- 변경 없는 재실행의 조회 재사용과 판정 이력과의 분리: 최초 캐시 파일 부재로 실패.
- 실패 조회 재사용과 `--retry-failed`의 재요청·새 revision: 최초 재요청 없음으로 실패.
- 조회 실패·정상 0건·후보 있으나 미확정의 구분: 최초 세 경우가 같은 결과로 실패.
- 키·응답 원문·공급자 전용 필드의 산출물·출력 미노출: 최초 조회 미구현으로 실패.
- 확정 복원명 반영 후 새 질의와 갱신된 판정: 최초 질의어 고정으로 실패.
- 좌표계를 확인할 수 없는 값의 보류(`missing_coordinates`): 최초 좌표 해석 부재로 실패.
- 키 없음의 기존 경로 유지와 한쪽만 있는 설정의 종료 코드 2: 최초 구성 검사 부재로 실패.
- 조회 캐시 변경 후 오래된 빌드 거부: 최초 의존성 미포함으로 실패.

## 최종 검사

이 환경의 uv는 PATH에 없어 저장소 로컬 `.tools/uv/bin/uv.exe`로 실행했다.
다음 명령은 저장소 루트 기준 PowerShell·Git Bash 공통이며, 실제 검사는 PowerShell에서 수행했다.

| 명령 | 결과 |
| --- | --- |
| `uv sync --locked` | 통과, 17개 잠금 패키지 확인 |
| `uv run pytest` | **110 passed**, 9.49초 |
| `uv run ruff check .` | 통과 |
| `uv run ruff format --check .` | 47개 파일 통과 |
| `uv run mypy src` | 소스 21개 통과 |
| `uv run python -m deliciousmap --help` | 종료 0, 기존 8개 명령 유지 |
| `git diff --check` | 통과 |
| gitleaks 스테이지 검사·커밋 훅 | 비밀 탐지 없음 |

## 제한

**실제 네이버 API를 호출하지 않았다.** 엔드포인트·인증 헤더·환경변수 이름은 `.env.example`과
SECURITY.md의 NAVER API HUB 결정을 따랐고, 응답 해석은 지역검색 응답 형식을 가정한 합성 응답으로만
검증했다. 실제 키로 한 건도 조회하지 않았으므로 실응답 필드·좌표계·오류 코드의 확인은 남아 있다.
운영 실행 전에 담당자가 실제 응답 한 건으로 해석 결과를 대조해야 한다.

지점명 분리는 등록된 장소 이름의 마지막 낱말만 본다. 이 규칙이 틀리면 근거와 어긋나
미확정으로 남을 뿐 다른 업소를 채택하지는 않지만, 실자료에서의 적중률은 검증하지 않았다.
좌표는 WGS84를 10^7배한 정수만 해석하고 그 밖의 값은 보류한다.

실제 수집·파서·분류기·인허가 HTTP·LLM·유료 호출·HTML/PWA·배포는 이 범위가 아니다.
저장은 단일 작성자용이며 자동 파일 분할은 없다. Windows 검사 결과로 Linux 실행 완료를 주장하지 않는다.
합성 테스트와 중간 JSON 빌드는 실데이터 동일 업소·좌표 품질 또는 제출 전 미해결 0건 검증이 아니다.
