## 구현과 TDD

부모 #36에서 사용자가 확정한 공개 CLI 경계에 합성 선행 산출물·후보·네트워크 차단·임시
디렉터리를 사용했다. 새 테스트는 실제 업소 판정·저장·마커 연결·정적 JSON 빌드를 실행한다.
`run`의 범위 밖 수집·파싱·분류만 합성 선행 어댑터로 제공한다.

실패→최소 구현→통과를 확인한 동작:

- 근거가 일치하는 기관 도시 밖 업소의 좌표·장부·마커 연결: 최초 `not-implemented` 실패.
- 조회 오류의 보존과 종료 1: 최초 종료 0 실패.
- 구버전 재생성 설명과 옛 산출물 보존: 최초 `invalid-artifact` 실패.
- 같은 확인 업소에 대한 좌표 근거 충돌: 최초 잘못된 `matched` 결과 실패.
- 실패 재사용과 명시적 재시도의 추가 이력: 최초 revision 누락 실패.
- 후보 자신의 주소를 독립 근거로 쓰는 경우: 최초 잘못된 `matched` 결과 실패.
- 20MB 초과 산출물: 최초 일부 이력이 저장되는 실패. 전체 크기를 먼저 검증하고 이력을 일괄 저장하도록 수정.

추가 검증은 검색 첫 오답 후보 건너뛰기, 동명 지점 분리, 비식당·판단 보류·미확정 장부 보존,
주소·지점 부재, 후보 0건·중복·이름 유사성·근거 충돌, 사람 확인의 범위 제한과 삭제,
후보 변경 후 오래된 빌드 거부, 변경 없는 성공 재사용, 안전한 오류 설명,
원본 없이 정제 파일만의 동일 빌드, 예전 상호 중심 이력 미사용을 포함한다.

## 최종 검사

이 환경의 uv는 PATH에 없어 저장소 로컬 `.tools/uv/bin/uv.exe`로 실행했다.
다음 명령은 저장소 루트 기준 PowerShell·Git Bash 공통이며, 실제 검사는 PowerShell에서 수행했다.

| 명령 | 결과 |
| --- | --- |
| `uv sync --locked` | 통과, 17개 잠금 패키지 확인 |
| `uv run pytest` | **78 passed**, 13.34초 |
| `uv run ruff check .` | 통과 |
| `uv run ruff format --check .` | 39개 파일 통과 |
| `uv run mypy src` | 소스 18개 통과 |
| `uv run python -m deliciousmap --help` | 종료 0, 기존 8개 명령 유지 |
| `git diff --check` | 통과 |
| gitleaks 스테이지 검사·커밋 훅 | 비밀 탐지 없음 |

## 제한

실제 수집·파서·분류기·네이버/인허가 HTTP·LLM·유료 호출·HTML/PWA·배포는 수행하지 않았다.
`closure`의 기본 동작은 인허가 미연결 상태를 `unknown`으로 보존하는 것이다.
저장은 단일 작성자용이며 자동 파일 분할은 없다. Windows 검사 결과로 Linux 실행 완료를 주장하지 않는다.
합성 테스트와 중간 JSON 빌드는 실데이터 동일 업소·좌표 품질 또는 제출 전 미해결 0건 검증이 아니다.
